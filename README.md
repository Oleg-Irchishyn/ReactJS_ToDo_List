# React JS Todo List App

A todo list app built with React, TypeScript, Redux (+ redux-form, redux-thunk), and SCSS modules. Organize tasks into color-coded lists, add/edit/complete tasks, and filter by list from the sidebar.

Data is served from [my-json-server](https://my-json-server.typicode.com/Oleg-Irchishyn/projects_db) (a shared `db.json` on GitHub) — there's no backend to run locally.

## Getting started

```bash
npm install
npm run dev-server
```

The app opens at `http://localhost:3000`.

## Scripts

- `npm run dev-server` — start the local dev server
- `npm run build` — production build, output to `web/` (used for the GitHub Pages deploy)
- `npm test` — run the test suite
